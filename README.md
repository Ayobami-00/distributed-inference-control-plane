# distributed-inference-control-plane
A Rust-native control plane for scheduling heterogeneous AI inference workloads across distributed, multi-region GPU fleets

The [final product scope](docs/final-product-scope.md) defines the proposed AWS EKS deployment, customer profiles, service objectives, GPU provider integration, cost accounting, and experiment workflow.

The [release roadmap](docs/release-roadmap.md) breaks that scope into cumulative versions, each with a runnable end-to-end experiment and an explicit release gate.
